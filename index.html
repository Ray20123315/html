Safety philosophy

先避免把「優化」做成新的問題。

不亂殺

系統程序預設受保護；Safe Close Advisor 先建議你正常關閉一般程式。

不假裝

1 ms 是取樣要求，不宣稱畫面真的 1000 FPS；polling 也不叫 true push。

不亂簽

沒有可信 Code Signing 憑證時，Release 會明確是 unsigned，不拿自簽冒充公開信任。

不偷追蹤

核心監控與 Log 留在本機；更新檢查只讀 GitHub Release metadata。

FAQ

第一次用也能看懂。

1 ms 會不會讓電腦更快？

不會。它只是讓資料引擎可以更密集取樣。大多數情況 10–100 ms 已足夠，畫面也不需要每毫秒重畫。

為什麼不做「一鍵清空 RAM」？

Windows 會主動使用 RAM 做快取；空白 RAM 本身不是效能目標。工具優先處理「壓力是否真的高、哪個程式在增長」。

Windows 顯示 SmartScreen 怎麼辦？

公開可信簽章需要正式 Code Signing 憑證或服務。專案不會用自簽憑證假裝已解決 SmartScreen。

更新通知是不是雲端推播？

目前不是。App 每 30 分鐘讀一次 GitHub Releases；發現版本變化才在本機通知。
